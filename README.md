# IPv4 子网计算器

一个轻量、响应式的 IPv4 子网计算器。使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖，可直接在浏览器中运行。

## 在线使用

[打开 IPv4 子网计算器](https://904897560.github.io/ipv4-subnet-calculator/)

## 功能

- 支持 `/0` 至 `/32` 的全部 IPv4 CIDR 前缀
- 联动选择子网掩码、每个子网的地址数和子网数
- 计算网络地址、主机地址范围、广播地址和反掩码
- 显示总地址数、可用主机数和 CIDR 标记
- 分页展示子网明细，支持每页 10、25、50 或 100 条
- 提供 IPv4 地址和 CIDR 前缀输入校验
- 适配桌面端和移动端
- 所有计算均在浏览器本地完成，不会上传网络地址

## `/31` 与 `/32` 支持

本项目修复了常见子网计算器无法正确处理 `/31` 和 `/32` 的问题：

- `/31` 按 [RFC 3021](https://www.rfc-editor.org/rfc/rfc3021) 处理，两个地址都可作为点对点链路端点，不保留网络地址和广播地址。
- `/32` 表示单个主机地址，常用于主机路由或环回接口，不存在广播地址。

## 本地使用

下载仓库后，直接用浏览器打开 `index.html` 即可：

```text
index.html
```

项目不需要 Web 服务器、包管理器或构建步骤。

## 使用示例

输入：

```text
192.168.1.0/24
```

选择 `255.255.255.192/26` 后，将得到 4 个子网，每个子网包含 64 个地址和 62 个传统可用主机地址。

## 部署

项目使用 GitHub Pages 发布，部署源为 `main` 分支的根目录。更新根目录中的 `index.html` 后，GitHub Pages 会自动重新部署。
